## 🔎 What Is Machine Learning?

**Machine Learning (ML)** is a branch of Artificial Intelligence (AI) that enables computers to **learn from data without being explicitly programmed**.  

Instead of writing hard-coded rules, ML models **find patterns in data** and use those patterns to make predictions or decisions.  

✅ Example:  
- Traditional programming → You write rules to detect spam emails.  
- Machine Learning → The model **learns spam patterns automatically** by analyzing thousands of emails.

## 📚 Types of Machine Learning

There are **three main types** of ML:  

1. **Supervised Learning** – Trained on labeled data (e.g., predicting house prices).  
2. **Unsupervised Learning** – Finds hidden patterns (e.g., customer segmentation).  
3. **Reinforcement Learning** – Learns through trial and error (e.g., training robots, AlphaGo).  

---

## 💡 Example: Predicting House Prices with ML

Imagine you have data about houses (size, location, rooms, etc.).  

- You feed past data into an **ML model**.  
- The model **learns the relationship** between features and price.  
- Next time, it predicts the price of a new house accurately.  

```python
# Simple ML example in Python with Scikit-learn
from sklearn.linear_model import LinearRegression

# Training data
X = [[1000], [1500], [2000]]  # house size (sq ft)
y = [200000, 300000, 400000]  # prices

model = LinearRegression()
model.fit(X, y)

print(model.predict([[1800]]))  # Predict price for 1800 sq ft house
```

## 🚀 How to Start Learning Machine Learning in 2025

If you’re a beginner, here’s the **step-by-step roadmap**:
